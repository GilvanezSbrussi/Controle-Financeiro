Backup dos dados

📊 Informações

💾 Exportar backup

Salva uma cópia dos seus dados em um arquivo JSON. Você pode escolher onde salvar o arquivo.

📂 Importar backup

Restaura seus dados a partir de um arquivo de backup exportado anteriormente. Selecione apenas o arquivo de backup desejado.

💡 Dica: Use "Procurar arquivo" para selecionar um arquivo específico, ou "Navegar pastas" para explorar diretórios.

🗑️ Limpar todos os dados

Remove todos os lançamentos e contas. Esta ação não pode ser desfeita. Faça um backup antes de continuar.

⚠️ Atenção! Tem certeza que deseja apagar todos os dados? Esta ação não pode ser desfeita. Todos os lançamentos e contas serão perdidos permanentemente.
