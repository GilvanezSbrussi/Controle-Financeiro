# Controle sua Fortuna - PWA

Esta e a versao instalavel pelo navegador do celular.

## Como testar no computador

Na pasta `pwa`, rode:

```powershell
npx serve .
```

Ou use qualquer servidor estatico e abra o endereco mostrado no navegador.

## Como instalar no celular Android

1. Publique esta pasta em um endereco HTTPS, como GitHub Pages, Netlify ou Vercel.
2. Abra o link no Chrome do celular.
3. Toque no menu do Chrome.
4. Escolha `Adicionar a tela inicial` ou `Instalar app`.

## Onde os dados ficam salvos

Os dados ficam no armazenamento local do navegador/app instalado. Para escolher uma pasta, use `Exportar backup`; o Android deixa voce salvar o arquivo em uma pasta ou servico de nuvem. Para restaurar, use `Importar backup`.
